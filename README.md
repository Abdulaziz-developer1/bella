# Bella

A beautiful, responsive website built using only HTML and CSS.

## 📝 Overview

**Bella** is a web project that demonstrates how to create visually appealing and fully responsive websites using only HTML and CSS—no JavaScript required. It’s perfect for learning clean, modern web design fundamentals or as a starting point for your own static site.

## ✨ Features

- **Pure HTML & CSS:** No JavaScript—just clean, maintainable code.
- **Responsive Design:** Adapts gracefully to desktops, tablets, and mobile devices.
- **Modern Layouts:** Utilizes CSS techniques for attractive sections and components.
- **Easy Customization:** Straightforward structure for quick adaptation to your needs.

## 🚀 Getting Started

1. Clone or download this repository.
2. Open `index.html` in your web browser.
3. Start customizing content and styles as you wish!

## 🗂️ Project Structure

- `index.html` — Main HTML file for the website.
- `style.css` — All custom styles for layout and appearance.
